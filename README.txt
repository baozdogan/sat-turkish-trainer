SAT Turkish Memory Trainer — iPhone PWA

This package is ready to host as a Progressive Web App (PWA).

To install on iPhone:
1. Upload this folder to any HTTPS web host (GitHub Pages, Netlify, Cloudflare Pages, your own website, etc.).
2. Open the HTTPS link in Safari on the iPhone.
3. Tap Share.
4. Tap Add to Home Screen.
5. Launch the app from the new Home Screen icon.

The app works offline after the first successful load.
Words and progress are stored locally on the device.
